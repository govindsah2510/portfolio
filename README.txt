GOVIND SAH — PERSONAL PORTFOLIO

FILES
- index.html       Home page
- about.html       About page
- skills.html      Skills page
- projects.html    Projects page
- contact.html     Contact page
- css/style.css    All styling and responsive layout
- js/script.js     Mobile menu, year and contact form behavior

HOW TO RUN
1. Extract the ZIP file.
2. Open the govind-portfolio folder.
3. Double-click index.html, or open it with VS Code and use Live Server.

PERSONALIZE BEFORE PUBLISHING
1. Add your photo: put an image named profile.jpg in the project folder, then replace the profile-placeholder blocks in index.html and about.html with:
   <img class="profile-photo" src="profile.jpg" alt="Govind Sah">
   Add this CSS rule in css/style.css:
   .profile-photo{width:100%;height:100%;object-fit:cover;border-radius:inherit}
2. Replace your-email@example.com in contact.html and js/script.js with your real email.
3. Replace sample project descriptions with your actual projects and add project links.
4. Update skills and education details as you learn more.

NOTE
The contact form opens the visitor's email app using mailto. It does not send/store messages by itself. For a hosted form, connect a form backend/service later.
